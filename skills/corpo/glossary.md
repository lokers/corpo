# Glossary

Literal sense of a phrase, so an idiom is not missed. This is not the joke. The notice-period samples in [examples.md](examples.md) set how rude or how oily the line should be. Context wins. Skip the note when the meaning is obvious.

## Meetings

### Revisit later
- Corpo: circle back once we have a clearer picture
- Colloquial: I'll come back to this once I know more

### Talk privately or later
- Corpo: let's take this offline
- Colloquial: let's talk about this separately
- Note: "offline" means later or privately, not "cancel the topic"

### Short check-in
- Corpo: let's put a quick sync on the calendar
- Colloquial: let's do a short check-in

### Add someone
- Corpo: I'll loop them in
- Colloquial: I'll add them to this

### Meet live
- Corpo: this deserves a live working session
- Colloquial: we should talk this through live

### Handle it in writing
- Corpo: let's take this async
- Colloquial: we can handle this in writing

### Share context first
- Corpo: please review the pre-read before we meet
- Colloquial: please read this before the meeting

### Stop without a decision
- Corpo: let's park this and close the meeting
- Colloquial: let's stop here and decide later

## Status

### Work has started
- Corpo: this is in flight
- Colloquial: we've started

### Not started yet
- Corpo: we haven't kicked this off
- Colloquial: we haven't started

### Stuck
- Corpo: we're blocked on this
- Colloquial: we're stuck

### Finished
- Corpo: this is wrapped and the loop is closed
- Colloquial: this is done

### Might miss the date
- Corpo: this is at risk
- Colloquial: we might miss the date

### On schedule
- Corpo: this is on track
- Colloquial: we're on schedule

### Date moved later
- Corpo: the date has slipped
- Colloquial: the date moved later

### Waiting on someone
- Corpo: this is pending their input
- Colloquial: we're waiting on them

## Feedback

### Needs another pass
- Corpo: let's do another pass before this goes further
- Colloquial: this needs another pass

### I disagree with the approach
- Corpo: I have concerns about this approach
- Colloquial: I don't agree with this approach

### This is good
- Corpo: this is strong work
- Colloquial: this is good

### Too vague
- Corpo: I need a clearer picture of the ask
- Colloquial: this is too vague

### Too long
- Corpo: let's tighten this
- Colloquial: this is too long

### Missed the goal
- Corpo: let's realign on the goal
- Colloquial: this missed the goal

### Try again
- Corpo: please take another pass
- Colloquial: please try again

## Ownership

### You are responsible
- Corpo: you own the outcome
- Colloquial: this is yours

### I will do it
- Corpo: I'll take point on this
- Colloquial: I'll do it

### Another team owns it
- Corpo: this sits with the other team
- Colloquial: the other team owns this

### Who decides
- Corpo: who is the approver
- Colloquial: who gets to decide

### Hand it over
- Corpo: I'll transition this to you
- Colloquial: I'll hand this to you

### We share the work
- Corpo: we'll partner on the delivery
- Colloquial: we'll split this

### Needs a named owner
- Corpo: this still needs a DRI
- Colloquial: someone needs to own this
- Note: DRI means the one person accountable, not a committee

## Time

### By the end of the day
- Corpo: please send this by EOD
- Colloquial: please send this by the end of the day
- Note: say which timezone if it isn't already obvious

### By the end of the week
- Corpo: let's target EOW
- Colloquial: let's aim for the end of the week

### Urgent
- Corpo: this is time-sensitive
- Colloquial: this is urgent

### Can wait
- Corpo: this is not on the critical path
- Colloquial: this can wait

### Need more time
- Corpo: I need more runway before I can commit
- Colloquial: I need more time before I can promise

### As soon as you can
- Corpo: at your earliest opportunity
- Colloquial: as soon as you can

### Must leave at a set time
- Corpo: I have a hard stop then
- Colloquial: I have to leave at that time

## Disagreement

### Push back
- Corpo: I'd push back on that
- Colloquial: I don't think we should do that

### Contradicts the decision
- Corpo: that doesn't match what we already aligned on
- Colloquial: that goes against what we decided

### Hold the scope
- Corpo: let's hold scope
- Colloquial: let's not add more to this

### Postpone the topic
- Corpo: let's table this
- Colloquial: let's come back to this later
- Note: in US workplace English "table" means postpone; in some UK usage it means "bring it up now." Ask if the room could mean either.

### This idea is risky
- Corpo: I see material risk in this approach
- Colloquial: this idea is risky

### I don't follow
- Corpo: help me understand the rationale
- Colloquial: I don't follow

### We already covered this
- Corpo: per the earlier note, this was already covered
- Colloquial: we already went over this
- Note: "per my last email" is a reminder, and it often lands as a scolding. Keep the reminder, drop the slap unless the source is already sharp.

### A problem called an opportunity
- Corpo: I want to surface an opportunity in the plan
- Colloquial: there's a problem in the plan
- Note: workplace "opportunity" often means a problem. Use the surrounding sentences to decide which one it is.

### A person called a resource
- Corpo: we need another resource on this
- Colloquial: we need another person on this
- Note: "resource" can mean a person, a budget, or a tool. Say which.

### Two meanings of POC
- Corpo: I'll send the POC
- Colloquial: I'll send the proof of concept
- Note: POC can mean proof of concept or point of contact. Ask if the sentence doesn't say which.
